⬇ Download sample bundle
  • Upload a single .zip file.
  • Questions live in one sheet, in a single .xlsx file (any filename) — columns: board, category, value, question, answer, question_media, answer_media.
  • Images are the only supported media for now — place them in a media/ folder next to the .xlsx file. The extension doesn't matter — just reference the file by name, e.g. poster.
  • Filenames in question_media/answer_media just need to match a file in media/ by name (extension ignored) — case-sensitive on the name itself.
  • Leave a media cell blank for no image — not "NA" or "-". Multiple images for one cell: comma-separate the filenames.
